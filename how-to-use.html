A short field guide

How to use AnimoSort

Build a readable week from your official EAF, then save the way you want courses and sections to look.

01

Import your EAF

On the timetable page, choose the official DLSU Archershub EAF PDF or drop it into the import area. AnimoSort reads it in this browser and turns its meeting rows into a Monday–Saturday timetable.

Importing a new EAF replaces only the displayed schedule. Your customization profiles stay available.

02

Choose or create a profile

The Customization profiles panel is available before or after an EAF is loaded. Select an existing profile or use New to create a named setup.

Profiles are independent. Switching one changes the presentation without changing your EAF or the other profiles.

03

Customize a timetable card

Click a timetable card or its color dot to open the editor. Save applies the changes; Cancel discards them.

Course color applies to every meeting of that course. Mode and professor apply to the selected section.

04

Understand the card lines

Cards use one consistent order:

CourseCode Section · color dot
Course title
Room: ... · F2F or Mode: Online
Professor: ... when entered
Time: ...

Professor names are manual and optional because the EAF does not provide them. Blank names stay hidden.

Long course titles, rooms, and professor names wrap onto additional lines; the timetable grows to keep the full card content inside its border.

05

Use colors, modes, and professors

Presets are shortcuts. The native color picker and hex field accept an arbitrary opaque hex color, and the exact chosen color is saved in the profile and carried into the timetable and PNG export.

Choose F2F or Online when the EAF’s inferred value needs a manual correction. Choose Use EAF value to remove that section override.

06

Download and import a profile

Use Download JSON to save the active profile. On another browser or device, use Import JSON; the imported profile is created separately and activated immediately.

Before downloading a timetable PNG, choose Match site, Light, or Dark from the PNG theme control. The timetable preview updates immediately to match the download.

This works before an EAF too: import a profile first, then load a future EAF and matching course/section values will apply.

07

Rename, reset, or delete

Rename profiles to keep them understandable. Reset colors returns Plain/Neutral colors; Reset section details returns EAF mode inference and removes professors; Reset everything does both while keeping the profile name.

The built-in Default profile is always kept. Reset this section clears only the selected section’s mode and professor details.

08

Privacy and compatibility

EAF parsing, profile validation, rendering, and downloads happen in the browser. Profiles use local site storage; clearing site data removes them, so keep a downloaded JSON backup.

AnimoSort supports official Archershub EAF PDFs from AY 2025–2026 Term 3 onward. Legacy Animo.sys EAFs are not supported. If an import fails, use the original PDF and keep it under 1 MiB.

09

Put your timetable in Google Calendar

An ICS (iCalendar) file is a portable calendar file. AnimoSort creates one weekly recurring event for each meeting, using your current course colors only in the timetable/PNG—not in the calendar file—and your active professor and F2F/Online details in the event text.

After an EAF is loaded, enter the term start date and term end date manually. Both dates are inclusive. A class appears on its first matching weekday on or after the start date and ends on its last matching weekday on or before the end date, so partial weeks are handled automatically. For example, a Monday class is first included on the following Monday when a term starts on Wednesday.

1 · Set the rangeEnter both term dates beside the timetable.
2 · DownloadChoose Export to Google Calendar (.ics), read the notice, then download.
3 · Import on a computerIn Google Calendar, open Settings → Import & export → Import, choose the .ics file and destination calendar, then select Import.

Using an iPhone? Download the .ics file to Files, send or move it to a computer, and import it through Google Calendar on the web. Google’s current instructions use a computer for ICS imports, even when the file was downloaded on iPhone.

Before you export: the notice appears on every download because importing the same file again may create duplicates. AnimoSort skips meetings with no occurrence in the selected range and reports the skipped count. If no meeting falls in the range, the download is blocked so you can correct the dates.
