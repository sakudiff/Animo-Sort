Calendar handoffPut your classes in Google Calendar About 2 minutes

An .ics file is a calendar file. AnimoSort creates weekly class events with your current professor and F2F or Online details.

  1. 1Enter the term datesUse the real first and last day of the term. Both dates are included.
  2. 2Download the .ics fileChoose Export to Google Calendar (.ics), read the notice, then download.
  3. 3Import on a computerIn Google Calendar, open Settings, then Import & export, then Import.
Using an iPhone?Save the .ics file to Files, then send or move it to a computer. Google Calendar currently imports .ics files through its desktop website.
Avoid duplicatesImport each file once. Importing the same file again can create another copy of every class.

Classes outside the selected dates are skipped. If no class falls inside the range, AnimoSort blocks the download so you can fix the dates.

How do class details work?Colors, mode, professor, and long text

A course color applies to every meeting of that course. Mode and professor apply only to the selected section. Choose Use EAF value to remove a manual mode override.

The color picker and hex field accept any opaque hex color. Professor names are optional and stay hidden when blank. Long details wrap, and the card grows to keep them inside its border.

What do the reset buttons change?Clear only what you intend to clear

Reset colorsReturns the profile to Plain or Neutral colors.

Reset section detailsUses the EAF’s mode again and removes professors.

Reset everythingDoes both while keeping the profile name.

Reset this sectionClears only the selected section’s mode and professor.

The built-in Default profile cannot be deleted.

Why did my EAF import fail?Check the file before trying again
  • Use the original official Archershub EAF PDF.
  • Keep the file under 1 MiB.
  • Use an EAF from AY 2025-2026 Term 3 or later.
  • Legacy Animo.sys EAFs are not supported.

Where is my information stored?Privacy, profiles, and backups

EAF parsing, profile validation, timetable rendering, and downloads happen in your browser. The EAF is not uploaded.

Profiles use this site’s local storage. Clearing site data removes them, so download a JSON backup for profiles you want to keep.
