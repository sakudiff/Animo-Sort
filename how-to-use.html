Quick startTurn your EAF into a timetable About 1 minute

Start with the official EAF. AnimoSort reads the PDF in your browser and builds a weekly view from the schedule rows it can understand.

  1. 1Get your EAFDownload the official Archershub EAF PDF.
  2. 2Import the PDFChoose Browse files or drag the file into the import area.
  3. 3Choose what is nextReview the week, edit a class, download a PNG, or export a calendar.
Your schedule stays in this browserThe EAF is parsed locally and is not uploaded. Importing another EAF replaces the displayed schedule; saved customization profiles remain available.

If an import fails, open More help below for the file requirements.

CustomizeMake the timetable yours About 2 minutes

Profiles save presentation and class-detail choices. They do not contain your EAF or timetable rows, so you can carry the setup between devices without exporting the schedule itself.

  1. 1Choose a profileSelect one or choose New to create a named setup.
  2. 2Select a classChoose a timetable card or its color dot to open the editor.
  3. 3Save your changesSet the identity, title, time, room or platform, delivery mode, color, or professor, then choose Done. Use This meeting for one-off changes or Paired meetings to share only the fields you change.
Async classes need a complete timeIf an EAF row says Async but has no time or room, it appears under Manual class details. Open Edit details and provide a day, start time, end time, and any missing identity or room values. Enter times with AM or PM, such as 7:30 AM. Choose F2F or Online when adding a time; Automatic keeps the async row without a fixed slot. The class joins the timetable only after the time slot is complete.

Classes in the same EAF course and section form a pair when AnimoSort can match their shared identity. Normal EAF differences, such as a Monday meeting paired with a Thursday meeting, stay separate automatically. If a class already has its own changes, the review names the conflicting fields: Use pair settings follows the shared pair, Use this meeting for both shares the listed differences, and Cancel keeps your draft. Online meetings use Platform or link; leave it blank to show Online, or paste a complete HTTP(S) URL when you want to carry a meeting link into the calendar export. F2F meetings use a physical room. Automatic restores editable class details from the imported EAF for the selected scope. Course colors stay unchanged.

Use the profile elsewhere

Choose Download JSON. On another browser or device, choose Import JSON. The imported copy becomes active without changing your other profiles. A profile JSON can include a meeting URL you entered, so share it only as deliberately as you would share that link.

Match your PNG

Choose Match site, Light, or Dark. The preview changes first, so the downloaded PNG looks as expected. A PNG is a static image and cannot carry a clickable Zoom link.

You can import a profile before loading an EAF. Matching courses and sections pick up the saved details later. Appearance and reset tools are under More details.

Calendar handoffPut your classes in Google Calendar About 2 minutes

An .ics file is a calendar file. AnimoSort creates weekly events from the current effective class details. An independently edited class uses its edited day, time, room or platform, and title, then repeats weekly through the selected term dates. An async class stays out until it has a complete manual time.

  1. 1Enter the term datesUse the real first and last day of the term. Both dates are included.
  2. 2Download the .ics fileChoose Export to Google Calendar (.ics), read the notice, then download.
  3. 3Import on a computerIn Google Calendar, open Settings, then Import & export, then Import.
Meeting links can travel with the eventFor an Online class, paste the complete https:// or http:// meeting URL into Platform or link. AnimoSort writes it to the event’s standard URL field and repeats it as Join link: in the description. Google Calendar imports the event details, but Google decides how to display the URL. A clickable link or native Join button is not guaranteed, and the URL does not create Google Meet conference data.
Using an iPhone?Save the .ics file to Files, then send or move it to a computer. Google Calendar’s official import flow is on the desktop website.
Avoid duplicatesImport each file once. Importing the same file again can create another copy of every class.

Classes outside the selected dates are skipped. If no class falls inside the range, AnimoSort blocks the download so you can fix the dates. A platform name such as Zoom is exported as text; only a complete HTTP(S) URL is treated as a link.

How do class details work?Colors, mode, professor, and long text

A course color applies to every meeting of that course. Professor names are optional and stay hidden when blank. Long details wrap, and the card grows to keep them inside its border.

Choose This meeting for a one-off course code, section, title, time, room, mode, or professor. Choose Paired meetings to share only the fields you change. Normal EAF differences between paired meetings are not errors. If an independent meeting conflicts with pair settings, the review lists the fields and lets you follow the pair, use this meeting’s values for both, or cancel.

Choose Automatic to restore editable details from that meeting’s EAF row. An independent meeting stays independent, and course colors remain unchanged. For an Online class, the room field is labeled Platform or link; a plain platform name stays text, while a full HTTP(S) URL can be carried into the .ics export.

What do the reset buttons change?Clear only what you intend to clear

Reset colorsReturns the profile to Plain or Neutral colors.

Reset section detailsUses the EAF’s mode and course details again, and removes shared and per-class overrides.

Reset everythingDoes both while keeping the profile name.

Reset this pairClears the selected source section’s shared details.

Reset this classClears the selected meeting’s independent details, or all details for a single meeting.

The built-in Default profile cannot be deleted.

Why did my EAF import fail?Check the file before trying again
  • Use the original official Archershub EAF PDF.
  • Keep the file under 1 MiB.
  • Use an EAF from AY 2025-2026 Term 3 or later.
  • Legacy Animo.sys EAFs are not supported.

Where is my information stored?Privacy, profiles, and backups

EAF parsing, profile validation, timetable rendering, and downloads happen in your browser. The EAF is not uploaded.

Profiles use this site’s local storage. Clearing site data removes them, so download a JSON backup for profiles you want to keep. A profile can contain any class details you entered, including a meeting URL; treat the JSON file as sensitive if the link is private.
