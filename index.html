Before you download your ICS file

An ICS file is a portable calendar file containing your class events. ICS importing works best on a computer. On iPhone, download this file, then send it to a computer and import it through Google Calendar Settings and Import & export. Importing the same file again may create duplicate events.

About AnimoSort

An independent tool, not affiliated with Archershub or DLSU. Your EAF is processed in the browser and never uploaded, stored, or shared.

Learn more about AnimoSort

Compatibility

Supports official DLSU Archershub EAFs starting AY 2025-2026 Term 3. Legacy Animo.sys formats are not supported.
